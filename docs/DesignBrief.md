# DesignBrief · 抵达 · Reach（GoalFlow）App UI 重构

> 修正说明：早期需求被误读为"独立落地页"。实际诉求是**优化重构抵达·Reach 整个 App 的 UI**。本 Brief 以 App 本身为交付对象。

## 产品定位
抵达 · Reach（内部包名 goalflow-frontend）—— 个人成长 / 任务管理 App，整合今日待办、四象限、记录（日记/日志/笔记）、农历日历、回顾数据、专注番茄钟、目标看板、维度分类。

## 目标用户
与现有 App 一致：希望把零散习惯与任务收进一个系统的个人用户；重度使用记录 + 待办 + 日历联动。

## 页面唯一目标（本次）
统一并升级 App 整体视觉语言为**液态玻璃（liquid glass）**风格，抛弃现有紫色/靛蓝系（`brand-gradient` 靛蓝→粉、`#6d28d9`），建立可扩展、可落到 React 的设计系统。

## 交付格式与精度
- 设计系统 Token 文档（配色/字体/间距/圆角/阴影/组件规范）
- 高保真可点击 HTML 原型（模拟侧边栏 + 页面切换），供审阅
- 确认风格后，再重构 `/workspace/frontend` 的 React 组件并接回已发布 App

## 美学方向（沿用 discovery 结论）
- 液态玻璃：磨砂半透、清透卡片、浮光渐变 blob
- 全新品牌视觉：蓝 `#2563eb` → 青 `#06b6d4` → 青绿 `#14b8a6` 渐变，替代紫
- 字体：Sora（标题）/ Plus Jakarta Sans（UI）/ Noto Sans SC（中文）
- 强约束：禁止 emoji 当 icon（改 SVG）；禁止三列等宽 icon 卡；禁止奶油底+赤陶橙、近黑底+酸性绿等默认审美

## 本次起步范围（已与用户确认）
先定"外壳"：**登录页 + 侧边栏 + 仪表盘（今日待办）**，统一导航/卡片/配色/玻璃质感语言，后续页面沿用扩展。
