│ 侧边栏同上 │ 今日待办              8月5日 周二    │

**信息优先级（两变体一致）**：第一眼=今日待办标题与未完成项；第二眼=关键统计/农历；第三眼=维度分组与侧栏导航。
**移动端**：侧栏收为底部 Tab 栏（今日/记录/日历/目标/更多），主区单列堆叠。

B1 更贴近现有信息结构、改造成本低、阅读路径清晰 → 推荐作为外壳定调基线；B2 可作后续「仪表盘增强」迭代。
