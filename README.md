# 抵达 · Reach · 清单分类 + 关联目标

复刻公众号文章《清单分类+关联目标，这才是高效的样子》的方法论：
把待办按 **工作 / 健康 / 学习 / 生活** 等维度分块管理，给每件事标 **优先级**，并 **关联目标**（蓝色文字标注），
让每天一眼看清在忙什么、每件事为了什么。

> 项目代号 **GoalFlow**，对外名 **抵达 · Reach**。

## 技术栈
- 后端：FastAPI + SQLAlchemy(async) + PostgreSQL（Docker 版）/ SQLite（发布版）
- 前端：React + Vite + Tailwind CSS
- 认证：JWT（多用户数据隔离）
- 运行：Docker Compose 一键启动 / 单端口发布版

## 快速开始（Docker + PostgreSQL，推荐本地开发）
```bash
# 1. 启动（首次会拉镜像 + 构建，稍等）
docker compose up -d --build

# 2. 打开前端
#    http://localhost:5173
#    后端 API: http://localhost:8000/docs
```

注册即自动预置「工作 / 健康 / 学习 / 生活」四个维度。

## 功能
- 维度分类：任务按「工作 / 健康 / 学习 / 生活」分块，避免大杂烩列表
- 优先级（紧急度）：低 / 中 / 高 / 紧急
- 重要度：低 / 中 / 高，与紧急度组合成**艾森豪威尔四象限**
- 关联目标：任务可挂到某个目标，看板上以蓝色文字显示；目标页显示**完成进度条 / 逾期数**
- 重复任务：每天 / 每周 / 每月，完成后自动顺延下一次
- 番茄钟专注：专注计时并自动记录专注时长
- 周回顾 / 数据看板：本周完成、连续天数(streak)、专注时长、各维度与目标进展
- 看板统计：左侧各维度待办计数
